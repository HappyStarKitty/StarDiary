# Chap4 矢量力学之动力学

!!! summary "本章纲要"
    - <b>牛顿三定律：</b>牛顿三定律，质点动力学问题；由运动定律导出动力学三大定理。 

    - <b>动量方法：</b>动量、动量定理和质心运动定理，动量定理的各种形式（矢量式、投影式和守恒式）；（对固定点和对运动点的）动量矩、（对固定点和对运动点的）动量矩定理，动量矩定理的各种形式（矢量式、投影式和守恒式）；由动量方法解决一般约束刚体系的动力学问题。

    - <b>达朗贝尔原理：</b>惯性力和达朗贝尔原理，达朗贝尔原理和动量定理、动量矩定理的等价性；刚体上惯性力系的简化；用静力学方法解决动力学问题的“动静法”。 

    - <b>能量方法：</b>动能、功和动能定理；有势力场、势能、机械能守恒定律。 

    - <b>动力学综合问题：</b>将动量方法和能量方法相结合，或者将动静法和能量方法相结合，解决一般约束刚体系的动力学问题。
