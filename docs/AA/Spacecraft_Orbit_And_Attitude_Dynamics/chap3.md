# Chap3 航天器导航

## 导航概念与分类

航天器导航就是轨道确定，航天器轨道确定可以分为两大类：<b>自主和非自主</b>

非自主测轨由地面站设备，例如雷达，对航天器进行跟踪测轨，并且在地面上进行数据处理，最后获得轨道位置信息

若航天器的位置和速度等运动参数用星上测轨仪器来确定，而该仪器的工作不依赖位于地球或其他天体的导航和通信设备，那么轨道确定是自主的

!!! note "航天器导航分类"
    - 测量对于天体视线的角度来确定航天器的位置
    - 测量地面目标基准来确定航天器的位置和姿态
    - 对已知信标测距
    - 惯性导航方法
    - 组合导航方法
